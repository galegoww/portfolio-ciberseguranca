## GitHub

Conta GitHub: `galegoww`. O repositório privado já foi criado. Para atualizar o conteúdo, envie os arquivos extraídos e confira o README na raiz.

1. Acesse o repositório `portfolio-ciberseguranca` na sua conta.
2. Selecione visibilidade **Private** enquanto revisa o conteúdo.
3. Extraia o ZIP. Envie os arquivos e as subpastas de dentro de `Portfolio_Ciberseguranca_Everton_Macedo`, preservando os caminhos relativos. Não envie apenas o ZIP.
4. Confira se o `README.md` aparece na raiz e se seus links abrem os projetos.
5. Faça a revisão pessoal e acrescente evidências das suas execuções antes de tornar público.

Se preferir usar Git e já tiver um repositório remoto vazio, execute dentro da pasta extraída:

```bash
git init
git add .
git commit -m "Adiciona base inicial do portfolio de ciberseguranca"
git branch -M main
git remote add origin https://github.com/galegoww/portfolio-ciberseguranca.git
git push -u origin main
```

O envio exige autenticação da sua conta. Se o repositório já contiver arquivos, prefira cloná-lo antes de copiar os arquivos atualizados e criar o commit. Não coloque tokens nos arquivos do projeto. Se o Git solicitar nome e e-mail de autoria, configure os dados que deseja associar aos commits.
